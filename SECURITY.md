# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Report it privately through GitHub:

1. Open the Security tab of this repository.
2. Click "Report a vulnerability".
3. Describe the issue and how to reproduce it.

This opens a private security advisory visible only to maintainers. GitHub notifies the maintainers directly.

## Scope

- `apps/javelind` — repository server and data plane
- JRP, the Javelin Repository Protocol (`packages/protocol`, `packages/sdk`)
- `apps/cli` — the `javelin` CLI
- `apps/web` — hosted forge web application

## Current state

Javelin is an experimental codebase and has not had a security review. Vulnerability response is best-effort. There is no bug bounty and no guaranteed response time.
